# Simulator label font

`jetbrains-mono-medium-ascii.ttf` is **JetBrains Mono Medium** (© 2020 The
JetBrains Mono Project Authors, <https://github.com/JetBrains/JetBrainsMono>),
licensed under the SIL Open Font License 1.1 (`OFL-JetBrainsMono.txt`). The
site already uses JetBrains Mono for data, so in-canvas body labels match it.

Subset 2026-10-07 from `fonts/ttf/JetBrainsMono-Medium.ttf` with fontTools
`pyftsubset --unicodes=U+0020-007E --layout-features='' --no-hinting` to
printable ASCII (every core and catalog body name is ASCII): 270 KB -> 8.7 KB.
Upstream SHA-256 `d16e6dc9…88109`, subset SHA-256 `843d2139…4d433`. Under the
OFL, a subset is a Modified Version; it keeps the original copyright notice and
license and is only bundled, not sold on its own.

`make` embeds the bytes into the binary (`build/label_font.inc`, generated by
`tools/embed_binary.py`), so labels draw from the first frame on both the
native and browser builds without another download.
