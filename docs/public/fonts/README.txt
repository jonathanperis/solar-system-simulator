Self-hosted web fonts for the Solar System Simulator Pages site.

The site serves these files from its own origin so pages make no third-party
font requests and the Content-Security-Policy can restrict font-src to 'self'.

Files (unmodified Google Fonts latin subsets, downloaded 2026-10-06):
- cormorant-garamond-latin.woff2         Cormorant Garamond, upright, variable weight
                                         (fonts.gstatic.com/s/cormorantgaramond/v21)
- cormorant-garamond-italic-latin.woff2  Cormorant Garamond, italic, variable weight
- jetbrains-mono-latin.woff2             JetBrains Mono, upright, variable weight
                                         (fonts.gstatic.com/s/jetbrainsmono/v24)

The license texts with each project's copyright notice are in
OFL-CormorantGaramond.txt and OFL-JetBrainsMono.txt.
